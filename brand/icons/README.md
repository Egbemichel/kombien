# Icon System

**Status: not started.** No icon set exists yet. This directory is a placeholder for when one is designed.

## Guidance for when this starts

Consistent with the rest of the visual identity (see [../strategy/brand-strategy.md](../strategy/brand-strategy.md#what-the-brand-should-avoid)):

- Avoid literal taxi, map-pin, or steering-wheel iconography as the *system's* visual language — a specific icon for "location" or "route" may still need to exist functionally, but the overall icon style shouldn't lean on generic mobility-app visual clichés.
- Icons should read clearly at small sizes (favicon/UI scale) and work in the one-color/monochrome treatment described in [../logo/usage-guidelines.md](../logo/usage-guidelines.md), once that exists.
- Stroke weight, grid size, and corner radius should be defined here once decided, and should stay consistent with whatever grid the logo system ultimately uses.

## Contributing an icon system

Propose a direction via a [design proposal issue](../../.github/ISSUE_TEMPLATE/design_proposal.md) before building out a full set — see the [brand change policy](../README.md#brand-change-policy).
