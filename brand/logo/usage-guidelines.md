# Logo Usage Guidelines

**Status: direction approved (see [README.md](README.md)), artwork not yet produced.** No logo file has been designed yet. This document defines the *sections* these guidelines will cover once real artwork exists, so contributors know what's coming and what not to assume in the meantime.

## Sections to be completed once a logo is approved

- **Primary logo** — the default lockup and when to use it.
- **Compact symbol** — the mark on its own, and when it's appropriate (favicons, small UI, social avatars).
- **Wordmark** — text-only version and when it's preferred over the lockup.
- **Light version / Dark version** — which backgrounds each is designed for.
- **Monochrome version** — single-color use cases (stamping, low-contrast print, etc.).
- **Clear space** — minimum padding around the mark.
- **Minimum size** — smallest size the mark remains legible at, in px and/or mm.
- **Background usage** — approved background colors/textures.
- **Incorrect usage** — a gallery of what not to do (stretching, recoloring, adding effects).
- **Color restrictions** — which brand colors the logo may appear in.
- **Favicon and app-icon usage** — how the symbol adapts to those formats.
- **Figma source location** — link, page name, and access notes.
- **Export naming conventions** — see [README.md](README.md#export-naming-convention).
