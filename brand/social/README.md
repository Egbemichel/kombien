# Social & Launch Assets

**Status: not started.** No social preview images, templates, or launch assets exist yet — directories below are placeholders (`.gitkeep`) until real assets are approved and added.

## Directories

| Directory | Purpose |
|---|---|
| `github-preview/` | The repository's social preview image (shown when this repo is linked/shared) |
| `templates/` | Reusable templates for social posts, announcements, etc. |
| `launch-assets/` | One-off assets for a specific launch or milestone |

## When adding assets

- Depends on the logo system existing first (see [../logo/README.md](../logo/README.md)) — social assets shouldn't be designed ahead of an approved mark.
- GitHub's social preview image should be tested at GitHub's actual crop/aspect ratio before being set as the repo's preview image.
- Follow the [brand change policy](../README.md#brand-change-policy) for anything that introduces new visual treatments not already covered by approved guidelines.
