# Naming

**Status: decided.** Kombien is the project's name going forward.

## Working name

**Kombien** — a play on the French *"combien?"* ("how much?"), the exact question at the center of every fare negotiation this project is about.

## Tagline

> Je paie combien?

Approved for use in-product (README, app copy, social presence, etc.) — no longer a placeholder line.

## Naming diligence

An informal search found one unrelated existing product with the same name: **"Kombien — Le Juste Prix"**, a French mobile price-guessing game (`fr.kombien.app` on Google Play) — a different category, unrelated to transportation or civic tech.

The project owner has since reviewed this with a legal professional and confirmed the name is clear to proceed with, including for registration and app-store use.

**Decision: final. Kombien is the name — for this repository, documentation, package names, trademark registration, and app-store submission alike.**

## If the name changes

A name change is a major brand change under the [brand change policy](../README.md#brand-change-policy) — it needs a design proposal or discussion and project-owner sign-off, and it should trigger an audit of every place the current name is referenced (README, package manifests, social previews, app-store metadata, this brand directory).
