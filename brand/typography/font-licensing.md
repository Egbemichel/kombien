# Font Licensing

**Status: reference links only.** No font files are redistributed in this repository — both typefaces below are open source and should be obtained from their official sources, not copied into `brand/` or anywhere else in this repo.

## Space Grotesk

- License: [SIL Open Font License 1.1](https://openfontlicense.org/)
- Official source: [Google Fonts — Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)
- Foundry: Floriane Grossi / Google Fonts

## JetBrains Mono

- License: [SIL Open Font License 1.1](https://openfontlicense.org/)
- Official source: [JetBrains Mono](https://www.jetbrains.com/lp/mono/)
- Foundry: JetBrains

## Why we link instead of redistributing

The OFL generally permits redistribution, but linking to the canonical source keeps this repository light, ensures contributors always get the current/correct version, and avoids this project needing to track upstream font updates itself. If a build pipeline needs the fonts vendored locally (e.g. for offline builds or self-hosting), that decision and its implementation should be documented here when it happens, including which version is pinned and why.

## For contributors

If you're setting up local development and need these fonts installed: download them from the official sources above rather than sourcing them from a third-party mirror.
